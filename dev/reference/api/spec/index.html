    Spec¶

    The structure of the 835 and the columns of each table. See The spec for the guide.

    Spec ¶

    The loop structure, element definitions and tables of a file format.

    DEFAULT_VERSION instance-attribute ¶

    DEFAULT_VERSION: Version

    The version of the default built-in spec.

    builtin staticmethod ¶

    builtin(version: Version = Version.V5010) -> Spec

    The built-in spec of version; it defaults to Spec.DEFAULT_VERSION. Raises ValueError for a version no built-in covers.

    from_json staticmethod ¶

    from_json(json: str) -> Spec

    The spec described by json; raises SpecError with the core message when it is not valid.

    from_packages staticmethod ¶

    from_packages(top: str, pool: Sequence[str] = ()) -> Spec

    The spec of the stack whose top package is the text top, with the package texts of pool as its bases; raises SpecError with the core's message when the stack does not load.

    builtin_packages staticmethod ¶

    builtin_packages() -> builtins.list[builtins.str]

    The package texts the library ships: the 5010 stack, then the 4010 editions. They are the pool of Spec.from_packages and validate_stack.

    patch ¶

    patch(patch: str | JsonObject) -> Spec

    A new spec with patch merged over this one; patch is JSON text or a JSON object (a dict of JSON values); raises SpecError when the result is not valid.

    to_json ¶

    to_json() -> builtins.str

    The spec's model as canonical JSON text: no key equal to its default, no null, keys of maps in name order. Raises SpecError when the model cannot be read or written.

    schema ¶

    schema() -> builtins.dict[builtins.str, pyarrow.Schema]

    The schema of every table of the spec, by name, in table order: one pyarrow.Schema per table, with the column names and Arrow types the tables of a parse with this spec have. A reference column (such as claim in services) holds the row of a row in another table, and its field metadata names that table under the key oxedi.parent. Needs pyarrow.

    loops ¶

    loops() -> builtins.list[builtins.str]

    The loop names, in spec order.

    column_source ¶

    column_source(table: str, column: str) -> ElementSource

    Where column column of table table reads its value, as the spec compiled it. Raises KeyError for a table or column the spec does not declare, and ValueError for a column that reads a segment index or an element of a repeated group, which has no single element.

    tables ¶

    tables() -> builtins.list[builtins.str]

    The table names, in name order.

    trigger_segment ¶

    trigger_segment(name: str) -> bytes

    The id of the segment that opens loop name, such as b"CLP", without the element conditions the trigger may add. Raises KeyError for a loop the spec does not declare.

    element_sources ¶

    element_sources(
    table: str,
) -> builtins.dict[builtins.str, ElementSource]

    Every column of table table that reads one fixed element, by name, in name order; a column holding a segment index or reading a repeated group is not listed. Raises KeyError for a table the spec does not declare.

    group_sources ¶

    group_sources(
    table: str,
) -> builtins.dict[builtins.str, GroupSource]

    Every column of table table that reads an element of each repeated group, by name, in name order; empty for a table without repeat. Raises KeyError for a table the spec does not declare.

    envelope ¶

    envelope() -> builtins.list[EnvelopeLoop]

    The envelope loops, outermost first: each loop whose end segment checks it, with its trigger and end segment ids and its control positions. Empty for a spec with none.

    ElementSource ¶

    Where a table column reads its value: one element, or one component of it, of a segment. It names only the segment, element and component a column reads, not the qualifier, loop, occurrence or pick that select which occurrence of that segment, so two columns reading the same position of differently qualified segments compare equal.

    segment property ¶

    segment: bytes

    The id of the segment the column reads, such as b"CLP"; for a named occurrence, the occurrence's segment; in a table with segment, that segment.

    element property ¶

    element: int

    The 1-based element position.

    component property ¶

    component: Optional[int]

    The 1-based component position, when the column reads one component of a composite.

    GroupSource ¶

    Where a table column reads its value in a segment that repeats a group of elements, one row per group: the element at offset inside each group, or one component of it. holds(position) says whether an element position of the segment is that element of some group.

    first property ¶

    first: int

    The 1-based position of the first group's first element.

    step property ¶

    step: int

    Elements per group.

    offset property ¶

    offset: int

    The 0-based position of the column's element inside each group.

    component property ¶

    component: Optional[int]

    The 1-based component position, when the column reads one component of a composite.

    holds ¶

    holds(position: int) -> builtins.bool

    Whether 1-based element position of the segment is the column's element in some group.

    EnvelopeLoop ¶

    A loop of the envelope: its end segment checks the loop it closes by a control number and a count.

    name property ¶

    name: str

    The loop's name in the spec, such as "interchange".

    trigger property ¶

    trigger: bytes

    The id of the segment that opens the loop, such as b"ISA".

    end property ¶

    end: bytes

    The id of the segment that closes the loop, such as b"IEA".

    opener_element property ¶

    opener_element: int

    The 1-based position of the control number in the trigger segment, such as 13 for ISA13.

    closer_element property ¶

    closer_element: int

    The 1-based position of the same control number in the end segment, such as 2 for IEA02.

    count_element property ¶

    count_element: int

    The 1-based position of the count in the end segment, such as 1 for IEA01.

    SpecError ¶

    Bases: ValueError

    A spec that cannot be loaded or patched; the message names the rule, the loop and key, and the datum.

    Version ¶

    An X12 release a built-in spec covers.

    V5010 instance-attribute ¶

    V5010: Version

    Release 5010.

    V4010 instance-attribute ¶

    V4010: Version

    Release 4010.

    text property ¶

    text: str

    The release number as text.

    all staticmethod ¶

    all() -> builtins.list[Version]

    Every version a built-in spec covers, the default first.

    JsonValue module-attribute ¶

    JsonValue: TypeAlias = Union[
    None,
    bool,
    int,
    float,
    str,
    Sequence["JsonValue"],
    Mapping[str, "JsonValue"],
]

    A value JSON can hold; an integer must fit in 64 bits and a float be finite.

    The sequence and the mapping are read-only types, so a list[str] or a dict[str, list[str]] is a value; at run time a list or a tuple and any registered Mapping are accepted, and bytes are refused.

    JsonObject module-attribute ¶

    JsonObject: TypeAlias = Mapping[str, JsonValue]

    A JSON object: a mapping whose keys are str and whose values are JSON values.

    validate_stack ¶

    validate_stack(
    top: str, pool: Sequence[str] = ()
) -> Valid | Invalid

    Whether the stack whose top package is top, with the packages of pool as its bases, loads: a Valid with what it holds and can do, or an Invalid with the reason. pool is a list of package texts.

    Valid ¶

    A stack of packages that loads.

    id property ¶

    id: str

    The top package's id.

    name property ¶

    name: str

    The spec's name.

    packages property ¶

    packages: list[str]

    The id of every package of the stack, bases first, the top last.

    write property ¶

    write: Capability

    Whether the spec's tables can be written back into a file, and why not.

    mask property ¶

    mask: Capability

    Whether the spec can mask patient data, and why not.

    changes property ¶

    changes: list[Change]

    What the editions and patches of the stack changed, in stack order.

    spec property ¶

    spec: Spec

    The spec the stack loads as.

    Invalid ¶

    A stack of packages that does not load.

    Capability ¶

    What a stack that loads can do beyond reading: whether it can, and when it cannot, one line per reason, each saying what to change.

    can property ¶

    can: bool

    Whether the stack can.

    reasons property ¶

    reasons: list[str]

    Why it cannot, one line each; empty when it can.

    Change ¶

    One difference between a package and the stack it builds on: the package that made it, where, and how.

    package property ¶

    package: str

    The id of the package that made the change.

    path property ¶

    path: str

    Where, from the spec's root, a dot between the names.

    kind property ¶

    kind: ChangeKind

    How the value changed.

    __str__ ¶

    __str__() -> builtins.str

    The change and its package, as one line.

    ChangeKind ¶

    How a change left a value, compared with the package it builds on: one member per kind of the core's change.

    NARROWED instance-attribute ¶

    NARROWED: ChangeKind

    It allows less than before.

    WIDENED instance-attribute ¶

    WIDENED: ChangeKind

    It allows more than before.

    CHANGED instance-attribute ¶

    CHANGED: ChangeKind

    It is neither narrower nor wider: a name, a type, a structure.

    REMOVED instance-attribute ¶

    REMOVED: ChangeKind

    It is gone.

    ADDED instance-attribute ¶

    ADDED: ChangeKind

    It is new.

    run_kit ¶

    run_kit(
    manifest: str, stack: Valid, files: Mapping[str, bytes]
) -> KitReport

    Runs the kit manifest (the manifest's text) on the validated stack stack. files maps each path kit_files lists, as the kit writes it, to its bytes: nothing is opened, and the caller keeps the paths under a root it trusts. Raises SpecError with the core's message when the manifest does not read or checks another package than the stack's top.

    kit_files ¶

    kit_files(manifest: str) -> builtins.list[builtins.str]

    The paths a kit manifest names, sorted: the files run_kit needs. They are relative to the manifest's folder and may hold .., so the caller keeps them under a root it trusts. Raises SpecError with the core's message when the manifest does not read.

    KitReport ¶

    What running a kit gave: one case report per case, in name order.

    package property ¶

    package: str

    The id of the top package of the stack the kit checks.

    passed property ¶

    passed: bool

    Whether every case passed.

    cases property ¶

    cases: list[CaseReport]

    Each case's report, in name order.

    CaseReport ¶

    What running one case gave.

    name property ¶

    name: str

    The case's name.

    passed property ¶

    passed: bool

    Whether every expected output matches.

    outcome property ¶

    outcome: KitPassed | KitDiffers | KitBroken

    How the case ended.

    KitPassed ¶

    A case whose every expected output matches.

    KitDiffers ¶

    A case where some expected output differs, one difference per output.

    differences property ¶

    differences: list[KitDifference]

    The differing outputs, in output order.

    KitBroken ¶

    A case that could not run: the file it names was not given, is not text or is not an X12 document.

    path property ¶

    path: str

    The file the fault names, as the kit writes its path.

    message property ¶

    message: str

    What failed and what to do.

    KitDifference ¶

    The first line where an output differs from the text the kit expects.

    output property ¶

    output: KitOutput

    The output that differs.

    file property ¶

    file: str

    The file that holds the expected text, as the kit writes its path.

    line property ¶

    line: int

    The 1-based number of the first line that differs.

    expected property ¶

    expected: str | KitEnd

    What the expected text has there: the line without its line break, or KitEnd when it ended before.

    actual property ¶

    actual: str | KitEnd

    What the run's output has there, as expected.

    KitOutput ¶

    The output of a run a case can expect: one member per output of the core.

    TABLES instance-attribute ¶

    TABLES: KitOutput

    The tables.

    DIAGNOSTICS instance-attribute ¶

    DIAGNOSTICS: KitOutput

    The diagnostics.

    KitEnd ¶

    The text of an output ended before the line a difference names.
